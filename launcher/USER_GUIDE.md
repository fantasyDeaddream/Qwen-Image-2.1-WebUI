# Qwen-Image-2.1 本地部署 · 使用说明

这个 EXE 里打包了运行所需的**全部脚本与代码**。你只需要分发这一个文件。

---

## 怎么开始

1. **双击 `QwenImageLauncher.exe`**
2. 第一次运行会在**同目录下自动展开** `shared\`、`setup\`、`mixed\` 等脚本文件夹（这是必需的：
   PowerShell 和 Python 需要真实的文件路径才能执行）
3. 等它检测完硬件和现有环境（几秒钟）
4. 按界面左侧的 5 个步骤走：

| 步骤 | 你要做什么 |
|---|---|
| **1 检测** | 什么都不用做，看结果就行 |
| **2 定位 / 安装路径** | 第 1 步全部 `OK` → 直接"下一步"。否则在这里指定已有环境的位置，或选一个安装目录 |
| **3 环境配置与模型安装** | 先"配置环境"和"安装 ComfyUI"，再在下面**点带 ★ 推荐的那一项**的"安装" |
| **4 启动与出图** | 选策略 → "启动模型 + WebUI" → 浏览器自动打开；下半部分是 AI Agent 面板 |
| **5 卸载** | 需要清理时再用 |

界面底部有实时日志，卡住时先看那里。

---

## 开始之前请确认

- **Windows 10 / 11 64 位**
- **NVIDIA 显卡**（8 GB 显存以上体验较好；没有独显只能用 CPU，会非常慢）
- **磁盘可用空间**：量化模型路线约 **15 GB**，全量原生模型路线约 **31 GB**
- **能联网**：第一次运行需要下载 Python 环境和模型（模型从 ModelScope 下载）
- **Python 和 git 不用自己装**，程序会自动准备

### 关于 Windows 的警告提示

本 EXE 没有代码签名证书，第一次运行时 Windows SmartScreen 可能弹出
"Windows 已保护你的电脑"。点 **"更多信息" → "仍要运行"** 即可。

## AI Agent（可选）

STEP 4 下半部分。填一家的 API Key，点"联网刷新 + 实测读图"，程序会**逐个实测**哪些模型
真的能读图（发一张 1×1 图片换取提供方的明确答复），然后只让你选实测通过的。

| 提供方 | 申请入口 |
|---|---|
| DeepSeek | platform.deepseek.com/api_keys |
| 智谱 GLM | open.bigmodel.cn/usercenter/apikeys |

API Key 用 **Windows DPAPI 加密**存储（只有当前 Windows 用户在本机能解开），
磁盘上不留明文，另存一份 SHA-256 指纹用来标识是哪把 Key。

不用 Agent 也能画：直接写提示词，点"**跳过 AI，直接绘图**"。

## 常见问题

**双击没反应 / 一闪而过**
从命令行运行它就能看到报错：地址栏输入 `cmd` 回车，再输入 `QwenImageLauncher.exe` 回车。

**第一次运行后多出来一堆文件夹**
正常。那是 EXE 展开的脚本，**不要删**。升级时只需替换 EXE 本身，
脚本会被自动刷新，而 `.venv`、`ComfyUI`、模型、`outputs` 都不会被动。

**下到一半断了**
重新打开 EXE 再点一次"安装"。已下好的文件会自动跳过，只补缺失的。

**显存不够 / 生成很慢**
用第 3 步里带 ★ 推荐的那一项（一般是量化 + Turbo，8 步出图，比 25 步快约 2.8 倍），
分辨率控制在 1024×1024 附近。参考图别放太多太大——多张高分辨率参考图会显著拉长耗时。

**想彻底删掉**
第 5 步的"卸载启动器组件"，取消勾选"保留已下载的环境与模型"，会连同环境、模型和缓存一起删除。

## 目录会变成什么样

```
QwenImageLauncher.exe     ← 你分发的唯一文件
shared\ setup\ mixed\ ... ← 首次运行自动展开的脚本（升级时自动刷新）
.venv\ ComfyUI\ models_cache\ outputs\   ← 安装环境/模型后出现，升级时保留
launcher_state.json       ← 记住的路径与加密后的 API Key
```
